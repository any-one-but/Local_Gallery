Disclaimer: Local Gallery runs locally in your browser. It never uploads your files and it cannot delete anything. It can rename files only when you explicitly run rename actions (Rename, Batch Index I, or Batch Index II). When your browser supports writable folder access, it stores logs and preferences inside a `.local-gallery` folder at the root you choose. If your browser does not support writable folders, it keeps those settings in browser storage instead.
## Basics
Local Gallery is a keyboard-first media viewer with mirrored controls so it can be used one-handed from either side of the keyboard. All actions are bindable now—open Menu → Keybinds to see or change what each action is mapped to.
## PANIC!
Trigger PANIC! at any time to mute audio and blank the window. By default it also opens a random safe site, which you can disable in Options. Trigger PANIC! again to return to normal.
## Getting Started
Choose a folder as your root with the `Choose Root` button. Pick the highest-level folder in your collection so subfolders appear in the Directories Pane. The Preview Pane will show whatever is currently selected. The first load can take a few seconds depending on folder size.
## Navigation
Use the Directories Pane on the left to move through folders and files. Moving the selection updates the Preview Pane on the right. You can enter folders, go back to the parent, and use the built-in search to filter what is visible in the current pane.
## Viewing & Playback
Preview mode shows the selected item inline. Gallery mode shows media fullscreen; you can still move through items and folders while in the gallery, or enable Alt Gallery Mode to make a folder-open action jump straight into fullscreen viewing. Video playback supports play/pause and seek steps; the seek step size is configurable in Options.
## Filters & Order
Use the media filter to show all media or only a specific type (images, videos, or GIFs). Random order reshuffles files per folder and keeps that order until toggled off. Folder behavior controls how you advance at the end of a folder: Slide (walks into the next folder), Stop (stops at edges), or Loop (wraps within the folder). Slideshow mode advances automatically and respects the active folder behavior.
## Organizing
Folders can be scored and sorted by score, tagged, favorited, or hidden. Tags can be applied to single folders from the folder menu or in bulk via multi-select. Hidden folders only appear when hidden mode is active. All of these actions are available from the on-screen menus and are bindable in the Keybinds tab.
## Keybinds & Cheatsheet
Open Menu → Keybinds to view or edit every action binding. You can also hold the cheatsheet action to temporarily display the keyboard overlay while learning your setup.
